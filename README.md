# PWM Based DC-DC Converter Control Using Verilog

## 📌 Project Overview

This project implements a **Pulse Width Modulation (PWM) generator using Verilog HDL** for DC-DC converter control applications.

The PWM signal is generated by comparing an **8-bit counter** with a user-defined duty cycle value. The design was simulated and verified using **Xilinx Vivado**.

> **Note:** This project simulates the digital PWM control signal. It does not implement the complete analog power circuit of a DC-DC converter.

---

## 🎯 Objectives

* Design a PWM generator using Verilog HDL.
* Generate different PWM duty cycles.
* Simulate the design using Xilinx Vivado.
* Verify PWM output using waveform simulation.
* Demonstrate approximately 25%, 50%, and 75% duty cycles.

---

## ⚙️ Working Principle

An 8-bit counter continuously counts from:

```text
0 → 1 → 2 → ... → 255 → 0
```

The counter value is compared with the `duty_cycle` input.

```text
If counter < duty_cycle
    PWM Output = HIGH
Else
    PWM Output = LOW
```

By changing the duty cycle value, the ON time of the PWM signal changes.

## 📊 Duty Cycle Values

| Duty Cycle Input | Approximate PWM Duty Cycle |
| ---------------- | -------------------------: |
| `8'd64`          |                        25% |
| `8'd128`         |                        50% |
| `8'd192`         |                        75% |

The duty cycle is calculated as:

```text
Duty Cycle (%) = (Duty Cycle Value / 256) × 100
```

## 📈 Simulation Signals

The following signals are observed in the waveform:

```text
clk
rst
duty_cycle[7:0]
counter[7:0]
pwm_out
```

In Vivado, duty cycle values may appear in hexadecimal format:

```text
40 (Hex) = 64 (Decimal)  → 25%
80 (Hex) = 128 (Decimal) → 50%
C0 (Hex) = 192 (Decimal) → 75%
```

---

## 📷 Simulation Result

The simulation verifies that the PWM pulse width changes according to the duty cycle input.

```text
Duty Cycle = 64  → Approximately 25% ON

Duty Cycle = 128 → Approximately 50% ON

Duty Cycle = 192 → Approximately 75% ON
```

As the duty cycle value increases, the **PWM ON time increases**.
